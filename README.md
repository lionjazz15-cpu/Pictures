# ChairMotion Fusion

VTuber 向けの、**装着ゼロ・ポン置き**の着席型3Dモーションキャプチャー。
座面＋背もたれの圧力マット、机下のセンサー（60GHz ミリ波レーダー／ToF）、既存の Webcam を融合し、**机に隠れて見えない骨盤〜足先**を中心に、着席中の全身姿勢を VMC / Warudo / VRM に出力する。

## 設計の要点（TL;DR）

1. **顔・腕・手は作らない**。既存のトラッキングに任せ、ChairMotion は「骨盤＋下半身」の専用プロバイダーに集中する。
2. **座面圧力は骨盤・接触・状態の担当**。足首・足先の3D位置は圧力では原理的に取れない（公開研究でも誤差は 9〜20cm 級）。
3. **机下レーダーの最大の壁は角度分解能**（IWR6843AOP では距離 0.4m で横方向に約 20cm）。両脚が**異なる距離**に来る斜めの配置、静止クラッタ除去の無効化、ヒートマップ入力で対処し、**ToF との対照実験で製品構成を決める**。
4. **椅子は回る・動く**。マットに IMU を内蔵し（身体には付けない）、椅子座標と机座標の変換を常に推定する。
5. 融合は「センサー表現・身体の事前分布・対応付け」を分けて学習する（Wave2Body 型）。少ないペアデータで学習でき、商用可能なデータだけで構築できる。
6. ボーンごとに **MEASURED / INFERRED / HELD** のタグを付けて出力し、製品の精度表記は実測のフレームだけで行う。
7. GPL（ChairPose）と SMPL 系は製品に入れない。人体モデルは Anny（Apache-2.0）または MHR を使う。
