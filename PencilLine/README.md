# PencilLine for Unity (Built-in RP)

Pencil+ 風のラインと、フラット化シェーダーのセットです。
映像制作 (Unity Recorder で書き出し → After Effects で撮影) 向けに、品質優先で作っています。

- 動作想定: Unity 2022.3.22f1 (VCC と同じ) / Built-in Render Pipeline / Windows (DX11)
- カラースペース: Linear (VRChat プロジェクトの標準)
- 対応シェーダー: lilToon / Poiyomi / Standard / **MToon (VRM 0.x・1.0 両方)**

---

## 導入

1. `PencilLine` フォルダごと `Assets/` の下に入れます。
2. アバターのアップロード用とは別の、映像用プロジェクトで使うのがおすすめです (VCC でプロジェクトを複製)。

---

## 0. まずアバターを丸ごと変換 (Avatar Converter)

`Tools > PencilLine > Avatar Converter` を開いて、アバターをドラッグ&ドロップします。

1. シーン上のアバター、プリファブ、VRM / FBX のどれでもOKです。全マテリアルが一覧に出ます。
2. 「基本の変換」を選びます。
   - **フラット化**: 全マテリアルを Flat Palette に変換 (lilToon のレイヤー焼き込み・MToon の影色も自動)
   - **元のまま・アウトラインだけオフ**: シェーダーはそのまま、lilToon / MToon のアウトラインだけ消す
3. 必要ならマテリアルごとに変換方法を変えます。半透明 (目のハイライト・頬染め) は既定で「元のまま」になります。
4. 「変換する」を押します。

**元のアバターとマテリアルは一切変更しません。**
- シーン上のアバター → 変換済みの複製 `名前_PencilLine` が隣にでき、元は非表示になります。
- プリファブ → 変換済みの**プリファブバリアント**が出力フォルダにでき、シーンにも置かれます。
- 作ったマテリアル・パレット・焼き込みテクスチャは `Assets/PencilLine_Converted/アバター名/` にまとまります。

変換後、一覧の「調整」ボタンでそのマテリアルを Flat Palette Maker で開き、色や統合を細かく直せます。

アウトラインの自動オフは、lilToon (アウトライン付きシェーダー → 通常版へ切り替え)、MToon 0.x / 1.0 (Outline Width Mode = None) に対応しています。Poiyomi はロック済みだと効かないので、ロック解除してから変換してください。

## 1. ライン (PencilLineEffect)

### 使い方
1. Main Camera を選び、`Add Component > PencilLine > Pencil Line Effect` を付けます。
2. Game ビューに線が出ます。
3. **シーンビューで見るには**: シーンビュー上部のエフェクトメニュー (重なった画像のアイコン) で「Post Processing」をオンにします。カメラの Tag が `MainCamera` である必要があります。シーンビューは常にプレビュー用の軽い設定で描かれます。

lilToon や MToon 側のアウトラインは**オフ**にしてください (線が二重になります)。MToon なら `Outline Width Mode = None` です。

### 既定値
新しく付けたコンポーネントは、これまでの調整で気に入った設定 (外周 3.91px・内側輪郭 3.64px・線色 黒・距離で細く オン など) で始まります。
すでにシーンにあるコンポーネントの値は変わりません。テクスチャ線は既定で 0 (オフ) です。

### 出る線の種類

| 種類 | 出る場所 | 調整 |
|---|---|---|
| 外周 | 背景との境目 | `Outline Width` |
| 内側輪郭 | 腕が体の手前にある時など、奥行きの段差 | `Inner Width`, `Depth Threshold` |
| 交差 | 別オブジェクト同士がくっつく・めり込む所 | `Intersection Width` |
| 材質境界 | 同じメッシュ内でマテリアルが変わる所 (服と肌など) | `Material Width` |
| 折れ目 | 法線が急に折れる所 (ハードエッジ) | `Crease Width`, `Crease Angle` |
| シワ | へこんだ所 (服のシワ・関節など)。ノーマルマップのシワも拾います | `Wrinkle Width`, `Wrinkle Scale`, `Wrinkle Threshold` |
| テクスチャ線 | フラット版の「書き影」の輪郭など、パレットで「線」にチェックした色の境界 | `Texture Width` |

### 服のシワを線にする (2通り)
- **形から**: `Wrinkle` 系の設定。モデルやノーマルマップの「へこみ」に線を引きます。細かいシワまで出る時は `Wrinkle Threshold` を上げる、大きなシワだけ欲しい時は `Wrinkle Scale` を上げます。
- **テクスチャから**: フラット化したマテリアルでは、テクスチャに描かれていた書き影 (シワの影) の輪郭が自動で線になります。Flat Palette Maker の「線」列で、どの色の境界に線を引くかを1色ずつ選べます。
  - フラット化していないマテリアルでも、`Texture Edge Threshold` を上げるとテクスチャの色の境目に線が出ます。

### 欲しい線だけ残す (強弱と間引き)
線の一本一本に「強さ」があります。奥行きの段差が大きい輪郭、深いシワ、急な折れ目ほど強い線です。
- `Emphasis`: 上げるほど、強い線は太く、弱い線は細くなります。手描きっぽいメリハリが出ます。
- `Min Strength`: これより弱い線を消します。上げていくと、大事な線だけが残ります。
- `Strong Depth Ratio`: どのくらいの奥行き差を「強い輪郭」とみなすか。
- 材質ごとの設定で、線の種類を1つずつオン/オフできます (例: 顔は外周だけ、服はシワも、髪は内側輪郭まで)。

### カリッとさせるコツ
- **Supersampling は 3** が既定です (2 でも十分きれい)。Play 中と書き出し時にだけ効きます (エディタ上は `Editor Preview Supersampling`)。
- さらに上を狙うなら **4K で書き出して AE で 1080p に縮小**。これが一番きれいです。
- 線の太さは `Reference Height` (既定 1080) 基準の px なので、4K で出しても見た目の太さは変わりません。

### 表現を詰める
- **色トレス**: `Color Trace` を上げると、線が「面の色を暗くした色」になります。肌は茶色、髪は濃い髪色の線になり、一気にアニメっぽくなります。
- **材質ごとの設定**: コンポーネントの右上メニュー (︙) →「画面に映っているマテリアルを材質リストに追加」で一覧が作られます。顔は `Crease Lines` をオフ、目や眉は `Draw Lines` をオフ、などを設定します。
- **マテリアルのアウトライン色を使う**: `Use Material Outline Color` をオンにすると、MToon や lilToon で設定済みのアウトライン色がそのまま線色になります。
- **影側を太く**: `Shadow Side Scale` を 1.5〜2 にすると、光の反対側の線が太くなります (手描きっぽい強弱)。
- **遠くを細く**: `Distance Reduction` をオン。Pencil+ の Reduction Settings に相当します。

### Game ビューが灰色になる時
旧バージョンでは環境によって元画像が読めず、灰色になることがありました。現在は「元画像をそのままコピー → 線を重ねる」方式にしたので直っているはずです。まだ灰色なら `Output Mode` が「線だけ」になっていないか確認してください。

### 線が出すぎる / 出なさすぎる時
- 斜めの面 (床や頬) に余計な線が出る → `Depth Slope Bias` を上げる。
- 内側の輪郭が出ない → `Depth Threshold` を下げる。
- 目のハイライトや頬染めの周りに線が出る → それらが不透明マテリアルなら、材質設定で `Draw Lines` をオフ。半透明マテリアルは既定で対象外です。
- 髪の毛先が半透明で線が欠ける → 材質設定で `Force Include` をオン。MToon の `TransparentWithZWrite` は自動で対象になります。

### 処理の重さ
Supersampling 2 × 1080p は軽めですが、4K × Supersampling 4 は 1 フレーム数百ミリ秒かかることがあります。映像書き出しでは問題ありませんが、作業中は `Editor Preview Supersampling = 1` にしておくのがおすすめです。

## 2. フラット化 (Flat Palette)

テクスチャの色を「決まった色数」に丸めるシェーダーです。
**模様は別の色として残り、グラデーションや書き影はベース色に統合されます。**
統合した書き影の色は、自動で「1影色」として再利用されます。

### 使い方
1. `Tools > PencilLine > Flat Palette Maker` を開きます。
2. **元マテリアル** に lilToon などのマテリアルを入れます。
3. **① 色を抽出** を押すと、色の一覧が出ます (自動統合も同時に行われます)。
4. 一覧を確認します。
   - 「統合先」で、どの色をどのベース色にまとめるか手で直せます。
   - 「ベース色」「1影色」は自由に塗り替えられます (＝色指定)。
5. **③ フラット版マテリアルを作成** を押すと、`元の名前_Flat.mat` とパレットが作られます。
6. **④ シーンで 元 → フラット に差し替え** でアバターに適用されます。「元に戻す」で戻せます。

作成後は、ウィンドウで色を変えるとシーンにリアルタイムで反映されます。

### 厚塗り・グラデーションの境界がジャギジャギになる時 (境界の整理)
なめらかなグラデーションや厚塗りの塗りムラをそのまま色の数に丸めると、色の境目がノイズ混じりの等高線になり、ガタガタします。
「**境界をなめらかに整える**」(既定でオン) は、抽出の時に次の処理をしてから、色の境界を**2倍の解像度**で焼き込みます。

1. エッジを残して塗りのムラをならす
2. 小さな色の島・細かいギザギザを、隣の似た色にまとめる
3. 境界をなめらかな曲線にしながら 2 倍に拡大する

色の差が大きい境界 (テクスチャに描かれた線、模様、目の書き込みなど) は形をそのまま残し、整えるのは**似た色どうしの境界**だけです。

- `整理の強さ`: 上げるほど塗りムラや小さな島が消え、境界がなめらかになります。模様や細かい書き込みまで消える時は下げてください。
- `境界の解像度`: 「2倍」がおすすめ。テクスチャに近づいて撮る時も境界がなめらかです。
- 結果は `フラット版の名前_Labels.png` として保存されます (色の番号が入った白黒っぽい画像。消さないでください)。色の変更・統合先の変更は、抽出し直さずにリアルタイムで反映されます。
- 2048px のテクスチャで 1 マテリアル数秒かかります。

### フラット度 (どれくらいフラットにするか)
ウィンドウの `フラット度` (マテリアルの `Flatness`) で、完全フラットと元の塗りの間を選べます。リアルタイムで反映されます。

- `1`: 完全にフラット (パレットの色だけ)
- 下げるほど、元の塗りの濃淡 (グラデーション・筆のタッチ) が戻ります。色指定 (ベース色・1影色) はそのまま効きます。
- 色の段差がやわらぐので、境界のジャギーも目立たなくなります。`0.6〜0.8` あたりが「セルっぽいけど厚塗りの味が残る」感じです。

### うまくいかない時
- **模様が消える** → 「色の数」を増やす。または「色相の許容差」「明度差の上限」を下げる。
- **影が残る** → 該当色の「統合先」を手でベース色に向ける。または「明度差の上限」を上げる。
- **白地にグレーの模様が消える** → 「明度差の上限 (白黒灰)」を下げる。

### lilToon のメイン2nd/3rd (デカール) は自動で焼き込み
元マテリアルが lilToon で、メイン2nd/3rd や色調補正 (HSVG) を使っていると、抽出の前に自動でメインテクスチャへ焼き込みます。

- 結果は `元の名前_Baked.png` として同じフォルダに保存され、フラット版マテリアルはこれを使います。元のテクスチャは変更しません。
- デカール (位置・拡大・回転・Copy・Flip Copy)、ブレンドモード (通常・加算・スクリーン・乗算)、アルファモード、マスク、MSDF、`_Color` に対応しています。
- デカールが細かくて潰れる時は「焼き込み解像度」を 2倍 に。
- 次の設定は焼き込めないので、ウィンドウに警告が出ます。
  - Left Only / Right Only / Flip Mirror (左右で模様を変える設定。両側に同じ模様が入ります)
  - UV1〜UV3 を使うレイヤー (UV0 として焼き込みます)、MatCap モード (除外します)
  - スクロール・デカールアニメーション (止まった状態で焼き込みます)、ディゾルブ、グラデーションマップ

### MToon から使う場合
MToon は最初から「ベース色」と「影色 (Shade Color / Shade Texture)」を分けて持っているので、それを活かします。

- 「MToon の影色を 1影色 に使う」がオンなら、パレットの各色について、MToon の影色をそのまま 1影色 にします (Shade Texture で部分ごとに影色が違っても、色ごとに平均を取ります)。
- 影の境界位置 (MToon 0.x の Shade Shift / Shade Toony、MToon 1.0 の Shading Shift) を引き継ぎ、フラット版は `Shade Mode = Cel` で作られます。
- カリング、Cutout / Transparent の設定も引き継ぎます。
- リムライト・MatCap・エミッションは引き継ぎません (フラットな見た目にするため)。

### シェーダーの設定
- `Shade Mode = Flat`: 完全にフラット (ライトの影響なし)。
- `Shade Mode = Cel`: ディレクショナルライトで 1 段のセル影。影色はパレットの「1影色」。
- `Receive Shadows`: 他のものからの影をくっきり受けます。
- `Light Color Influence`: 0 なら色指定そのまま (アニメ向き)。

## 3. 書き出しと撮影 (AE)

おすすめは、**色と線を別々に書き出して AE で重ねる**方法です。線の色や太さの調整、ボカシなどを後からできます。

### 方法 A: 線 PNG をコンポーネントから直接書き出す
1. `Output Mode = 合成` のまま、`Export Line PNG` をオン。
2. Unity Recorder で色 (線込み) の連番を録画しながら Play すると、`Recordings/Lines/` に**透過の線だけの PNG** が同時に出ます。
3. 線なしの色が欲しい場合は、`Output Mode = オフ` で Recorder を回し、線 PNG は別テイクで書き出してください。
   - Recorder を使わない場合は `Set Capture Framerate` をオンにすると、フレームレート固定で書き出せます。

### 方法 B: カメラを 2 台に分ける
- 色用カメラ: PencilLineEffect なし (またはオフ)
- 線用カメラ: `Output Mode = 線だけ`、Culling Mask = Nothing、背景を透明に
- Recorder の Targeted Camera で、それぞれを透過付きで録画します。

### アニメっぽさを上げる設定
- アニメーションは **2 コマ打ち / 3 コマ打ち** (24fps で 12 / 8 枚)。Timeline のキーを Constant 補間にするか、Recorder を 24fps にしてアニメーション側を間引きます。
- カメラの **FOV は狭め** (20〜30 度)。パースが弱まってセルっぽくなります。
- ポストエフェクトを使う場合、**トーンマッピングは None** (色指定がずれるため)、アンチエイリアスは TAA ではなく本ツールのスーパーサンプリングで。

## Pencil+ との違い (正直なところ)

このツールは「画面上の情報から線を検出する」方式です。Pencil+ の多くの線種 (外周・交差・材質境界・折れ目・距離減衰・材質ごとの線色) は再現できますが、次の点はまだできません。

- **入り抜き・ブラシの筆致**: Pencil+ はメッシュの辺から「ストローク」を作るので、線の始まりと終わりを細くできます。本ツールは線をつながったストロークとして扱っていないため、入り抜きはありません。
- **隠れ線**: 物体の裏に隠れた線は描けません。

入り抜きが必要になったら、次の段階として「Compute Shader でメッシュからエッジを抽出してストロークにする方式」を追加で作る必要があります。

## ファイル構成

```
PencilLine/
  Runtime/PencilLineEffect.cs     … カメラに付けるライン本体
  Runtime/MaterialAdapter.cs      … lilToon / MToon などの違いを吸収して読む
  Editor/AvatarConverterWindow.cs … アバター一括変換 (D&D)
  Editor/OutlineUtil.cs           … シェーダーのアウトラインをオフにする
  Editor/PaletteBuilder.cs        … パレット作成の本体 (一括変換と共用)
  Editor/FlatPaletteWindow.cs     … パレット作成・調整ツール
  Editor/LabelMap.cs              … 境界の整理 (塗りムラの平滑化・島の除去・なめらかな拡大)
  Editor/LilToonBaker.cs          … lilToon のレイヤー焼き込み
  Shaders/PencilLineGBuffer.shader… 線検出用の情報を書き出す (内部用)
  Shaders/PencilLineEdge.shader   … 検出・太らせ・合成 (内部用)
  Shaders/FlatPalette.shader      … フラット化シェーダー
  Shaders/LilToonBake.shader      … 焼き込み用 (内部用)
  Shaders/PencilLineCommon.cginc  … 共通関数
```
