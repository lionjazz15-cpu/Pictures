# 04. 実装計画・部品・原価・リスク

> 価格はすべて**概算**（2026年10月時点の想定、為替・流通で変わる）。発注前に販売店で見積もりを取ること。

## 1. 最短の MVP（8〜10週）

**MVP の定義**：「椅子に座ると、Warudo のアバターの骨盤と脚が、座り方・脚組み・前傾・寄りかかり・足の揺すりに合わせて**自然に**動く」。
この段階の脚は **INFERRED（推定アニメーション）**であり、実測とは呼ばない。

| 週 | 作業 | 成果物 |
|---|---|---|
| 1 | 部品の発注、記録基盤（Python＋LSL）、VMC 送信の雛形 | Warudo に固定ポーズを送れる |
| 2〜3 | 16×16 マット（Velostat、psa 型の回路）の製作、ESP32-S3 のファームウェア、ヒートマップのビューア | 60Hz の圧力ストリーム |
| 4 | 圧力の特徴量（COP・左右の坐骨の荷重・合計荷重・太もも領域）→ ルールと小型の分類器で状態を判定 | 着席・離席・脚組み左右・前傾・寄りかかり |
| 5 | 状態 → 骨盤の傾き・回旋（連続値）＋**状態ごとの脚ポーズのブレンド**（手作業のポーズ集） | Warudo で脚が動く |
| 6〜7 | IWR6843AOPEVM の点群を取得・可視化（静止クラッタ除去は無効）。**脚の領域のドップラーの強さ** → 足の揺すり・膝の上下の振幅を左右別に推定 | 足の揺すりが反映される |
| 8 | マットに IMU を追加 → 椅子のヨー | 椅子を回してもアバターが破綻しない |
| 9〜10 | 遅延の計測、UI の整備、配信での試験 | MVP のデモ動画 |

MVP は「研究の Phase 1〜2 の計測」を兼ねる。Phase 2 の Go/No-Go（02 §10）の評価は MVP と並行して行う。

## 2. 個人開発で着手する順番（全体）

1. **記録基盤と時刻同期**（あとから作り直すと全データが無駄になるため最初に）
2. 圧力マット 16×16（MVP）
3. 机下レーダー＋ToF の観測性テスト（**最大リスクを早く確認する**）
4. 正解の取得系（Vive / Tundra トラッカー：骨盤・左右の太もも・左右の足。ベースステーションは**机の下が見えるように低い位置の左右**に置く）
5. 32×32 ＋背もたれ＋IMU のマット v1
6. データ収録（パイロット3名 → 本収録）
7. ベースライン（A〜G）→ 融合モデル
8. 製品の実行環境（Rust / C++ ＋ ONNX）＋ Warudo プラグイン
9. 製品化（技適・筐体・量産マット）

## 3. 実験計画（Phase 5 の比較構成）

| 構成 | 入力 |
|---|---|
| A | 圧力のみ |
| B | レーダーのみ |
| C | 圧力＋レーダー |
| D | Webcam＋圧力 |
| E | Webcam＋圧力＋レーダー |
| **F（追加）** | Webcam＋圧力＋ToF |
| **G（追加）** | Webcam＋圧力＋レーダー＋ToF |

評価：被験者を1人ずつ除外する評価（LOSO）と、椅子を1脚ずつ除外する評価（LOCO）。指標は MPJPE（骨盤・膝・足首・足先に分けて）、PA-MPJPE、関節角度の誤差、状態の F1、追跡不能率、ジッター（加速度の RMS）、静止時の架空の動きの率（REQ-08）、遅延。各構成の差は**被験者単位のブートストラップ信頼区間**で報告する。

### データセットの規模（目標）

| 段階 | 被験者 | 椅子 | 机 | 内容 |

## 6. 実装の難易度

| 要素 | 難易度 | 理由 |
|---|---|---|
| 圧力マット 16×16 と表示 | ★☆☆ | 先行例が多い |
| VMC 出力・Warudo 連携 | ★☆☆ | 仕様が公開されている |
| マット IMU による椅子のヨー推定 | ★★☆ | ドリフト補正にカメラとの融合が必要 |
| 圧力マット v1（ゼロ電位法・校正・耐久性） | ★★☆ | アナログ回路と材料の評価 |
| 時刻同期・自動キャリブレーション | ★★☆ | 地味だが精度を左右する |
| 机下レーダーで静止した脚を検出・左右を分離 | ★★★ | **研究の前例がない** |
| 融合モデルの学習（少ないペアデータ） | ★★★ | データの収録コスト |
| 技適・量産 | ★★☆ | 費用と期間（専門業者に委託） |

## 7. 研究上の最大リスクと対策

| # | リスク | 影響 | 早期の検出方法 | 対策 |
|---|---|---|---|---|
| R1 | **机下レーダーの角度分解能が足りず、両脚を分離できない・静止した脚が消える** | 下半身の MEASURED が成立しない | Phase 2 の Go/No-Go（6〜7週目） | 斜めの配置 → ヒートマップ入力 → ToF の併用 → 2台構成 |
| R2 | **椅子の回転・移動で座標系が崩れる** | 脚がアバターの身体から離れる | MVP の 8週目 | マット IMU＋カメラのヨー補正＋運動学の拘束（02 §6.3） |
| R3 | 正解データの取得が難しい（机でトラッカーが遮られる） | 学習・評価ができない | パイロット収録 | ベースステーションを低い位置に置く、横からのカメラで三角測量を補助、収録時は机の幕板を外す |
| R4 | 机の多様性（金属・引き出し・幕板）でレーダーの汎化が効かない | 一部の環境で使えない | 3種の机で LOCO 評価 | 設置ごとに背景を学習＋対応する机の条件を仕様で明示 |
| R5 | Velostat のドリフト・へたり | 長時間の配信でずれる | 30分の連続試験 | 材料の変更・正規化入力・離席ごとのゼロ点更新 |
| R6 | 体型の多様性（小柄・大柄・脚の長さ） | 一部のユーザーで精度が落ちる | 身長別の誤差の分析 | Anny による体型の合成データ、被験者の幅を広げる |
| R7 | 期待値のずれ（「フルトラと同じ」と受け取られる） | 返品・評判 | ベータテスト | ソースタグの表示、MEASURED と INFERRED を分けた精度表記 |
| R8 | 技適の費用と期間 | 発売の遅れ | 製品の設計前 | 技適済みモジュールの採用、または ToF 構成 |

## 8. 将来の拡張（優先度順）

1. **フットマット**（床の圧力シート）：床に着いている足の XY 位置と接地を cm 単位で実測でき、foot lock の精度が大きく上がる。装着ゼロ・ポン置きの原則にも合う。
2. 机下センサーの2台構成（左右）
3. IMU グローブ（手指が隠れる場合）
4. 立位モード（床マット＋カメラ）
5. 小物のトラッキング
