# 03. 商用ライセンス確認表

> 本表は技術者による一次整理であり、法的助言ではない。製品出荷前に、各 LICENSE・利用規約の原文（取得日付き）を保存し、弁護士・弁理士の確認を受けること。
> 確認日：2026-10-24。✅ = LICENSE ファイル／公式ページで確認、⚠️ = 未確認または条件付き、❌ = 商用不可（または別契約が必要）。

## 1. 区分ごとの原則

| 区分 | 原則 |
|---|---|
| 論文 | アイデア・数式は著作権の対象外。**再実装は自由**（ただし特許は別途調査する） |
| コード | LICENSE に従う。**GPL のコードは製品に組み込まない**（クリーンルームで再実装する。GPL コードを読んだ担当者と実装担当者を分ける運用が望ましい） |
| 学習済み重み | コードとは**別ライセンス**のことが多い。学習データの条件を引き継ぐ場合がある |
| データセット | 「研究目的のみ」が多い。**商用モデルの学習に使えるか**を個別に確認する |
| 人体モデル | SMPL 系は商用に別契約が必要。**Anny / MHR を使う** |
| SDK・ファームウェア | ベンダーのライセンス（多くは「当該ベンダーのデバイス上でのみ使用可」） |

## 3. 障害と代替策

| 障害 | 代替策 |
|---|---|
| ChairPose が GPL | 2段生成モデル＋物理拡張という**アイデアを再実装**（アイデアは著作権の対象外） |
| SMPL 依存の研究が多い | Anny / MHR でスケルトンと形状を表現し、出力は VRM Humanoid のボーンに直接合わせる |
| 公開レーダーデータの多くが非商用 | Wave2Body 型の分離学習で、**ラベルなしのレーダーデータ**（自社で大量に安く集められる）と**姿勢のみのデータ**（CMU / 自社）を活用し、ペアデータの必要量を減らす |
| ベンダーの SDK に縛られる | 信号処理の上位層（ヒートマップ以降）を自社コードに寄せ、チップ固有の部分を薄くする |
| 特許 | 「圧力マット×姿勢推定」「レーダー×姿勢推定」の特許を J-PlatPat / Google Patents で調査（Phase 3 までに）。自社の新規性（机下配置・椅子座標の追従・ソースタグ付き出力）は出願を検討 |
