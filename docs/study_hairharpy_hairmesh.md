# HairHarpy / HairMesh 研究ノート

Toon Hair Studio の改良に向けて、次の2つの仕組みを調べたメモです。

- [HairHarpy 2.0](https://github.com/Rackta/HairHarpy)(catarackta、C++/Qt6/Vulkan)
- その Blender 移植版 [HairMesh](https://github.com/riel-gab/hairmesh)(Riel、GPL-3.0)

> **ライセンス上の扱い**
> - HairHarpy は source-available ライセンスです。読んで研究するのは自由ですが、コードの一部を他の製品に入れるには作者の許可が必要です。
> - HairMesh は GPL-3.0 ですが、手法そのものは catarackta 氏のものです。
> - このノートには**考え方とアルゴリズムの要約だけ**を書いています。コードは一切コピーしていません。Toon Hair Studio に取り入れる場合も、独自に実装します。

## 1. データモデル(両者共通)

| 要素 | 中身 |
|---|---|
| アンカー | グローバルな点。**カーブはアンカーIDの列**として表す。2本のカーブが同じアンカーを持てば「溶接」された状態 |
| カーブ | アンカーを通る3次ベジェ。ハンドルは保存せず毎回計算する(Bessel 接線 `d0·h1/h0 + d1·h0/h1`、長さは弦の1/3 × smooth) |
| 共有接線 | 共有アンカーでは、通るすべてのカーブの接線を平均する。そのため**共有区間のカーブは完全に同じ形**になる |
| Y分岐 | 枝の端はホストの接線を受け継ぎ、ハンドルを1.35倍にする(股の部分がシャープになる) |
| 壁(Wall) | 2本のカーブ a, b の間に張る面。パラメータは列数・列の寄せ・膨らみ・反転・ツイン(b→a の2枚目の面でレンズ状の房になる) |
| 房(Lock) | 壁でつながったカーブの連結成分。2本ならリボン、3本以上の閉じた輪なら立体の房。**隣の房とは縁のカーブを共有する** |
| トランク | 別々の房のカーブが、2つ以上連続したアンカーを共有している区間(合流・分岐) |
| ネットワーク(HH) | 編集のたびにカーブを分岐点で切り分け、重複を統合し、まっすぐ続く部分は再結合するグラフ |

## 2. 壁の面

「NURBS」と呼ばれていますが、実際は**直線織面(ruled surface)に正弦の膨らみを加えたもの**です。

```
q = A(t) + s·(B(t) − A(t)) + n · bulge · |B − A| · sin(π s)
```

- A, B:両カーブを弧長で等間隔に取り直した点
- s:列の位置(寄せ・偏りでべき乗やメビウス的な歪みをかける)
- n:行の接線 × 幅ベクトル
- 外向きの判定は**いちばん幅の広い行で1回だけ**行い、そこから行ごとに符号を伝える。毛先が細くなっても法線が裏返らない
- 膨らみは、つむじの根元と合流部でフェードさせる

## 3. ループ(行)の配置:均等配分

両者とも、ループは**房の中心線(スパイン = 房のカーブの平均)に沿って並べた平面**で決めます。

1. 密度を `f(s) = (1 + 曲がり)·(1 + 0.5·毛先ゾーン) × 塗り密度 × ガイド` とする(曲がり = 長さあたりの回転角を平滑化したもの)
2. ステップ幅を `step(s) = h / f`(h = ループ間隔)とする
3. `G(s) = ∫ ds/step` を等間隔に区切った位置にループを置く(累積分布の逆関数)。ガイド位置ではループが必ずそこに来るよう区間を分ける
4. 各ループ平面と、房の各カーブとの交点が頂点になる。**1枚の平面が全カーブを1点ずつ切るので、行数は自動的にそろう**
5. 仕上げの処理:
   - 細すぎる行の削除
   - 間隔が開きすぎた所への行の挿入
   - 行を角に対して直角にそろえる反復
   - 折れの検出(30°以上の曲がりと幅の1.5倍以上の隙間があれば行を挿入)
   - 「水平 ↔ 房に垂直」のループ向きスライダー(HM)

## 4. 継ぎ目と溶接

**継ぎ目のなめらかさは「上流」で決まります。** 共有アンカーと共有接線によって共有カーブが同じ形になり、同じ平面で切るので頂点も一致します。後から縫い合わせたり、スムージングしたりはしません。

- **親子の房の行の継承**:子の房のスパインが親の楕円断面の中にある間は、親のループ平面をそのまま使います。離れた後は、自分のステップに3hかけて移ります。後から作った房の行は、先に作った房にも差し戻すので(backfill)、T字頂点が残りません。
- **溶接パス**:
  1. 空間ハッシュと union-find で近い頂点をまとめる(同じ面の頂点同士や、共通の隣接頂点を持つ点同士はまとめない)
  2. 重複した面と、相手の房に埋もれた面を削除する
  3. 16辺以下の穴をクワッドの梯子で埋める
- **行ごとの輪郭(HH)**:
  1. 断面上でカーブをノード、壁を辺としたグラフを作り、外周をたどって輪郭にする
  2. 隣の行の輪郭とは、列キーの最長共通部分列(LCS)で対応を取ってつなぐ
  3. 列数が違う所は、最短の辺に三角形を入れて吸収する

## 5. 分岐・つむじ・その他

- **Y/X 合流(Unite)**:重なった縁を平均の経路の上にある共有アンカーで置き換え、向き合った壁を消して合流用の壁を追加します(膨らみはフェード)。
- **毛先**:
  - 尖り:縁のカーブが毛先のアンカーを共有するので、幅が0になって溶接される
  - 徐々に細く:毛先に向かって1行ごとに隣接列を1つずつ統合し、三角形で終わらせる
- **つむじ(Crown)**:
  - 分け目カーブと下側の接続カーブの間に、縦のループを敷く
  - 房の根元の列は、つむじのループに 1:1 でつなぐ
  - 渦の中心では、1点に集まるループを2本までに制限し、1組ずつ終わらせる(1回につき三角形1枚)
- **断面スイープ(Tube/Rib)**:中心線と幅から縁カーブを作り、同じパイプラインに流します。カールやノイズも、縁カーブを作ってから壁にします。
- **三つ編み**:リサージュ曲線 `(A sinθ, h sin2θ)` で、位相をずらして配置します。
- **UI**:
  - ライブ / ベイクの切り替え
  - 変更された房だけを作り直す
  - ループのプレビュー表示
  - つながりの診断(赤/緑で表示)と自動修正
  - 密度ガイドと密度ペイント

## 6. Toon Hair Studio との比較

| | HairHarpy / HairMesh | Toon Hair Studio |
|---|---|---|
| 房の定義 | 縁のカーブ2本以上(隣と共有) | 中心線1本 + 幅 + 断面スイープ |
| 厚み | カーブを増やすか、膨らみ + ツイン面 | 断面プロファイル(レンズ/山形/丸)で自動 |
| 継ぎ目 | 共有カーブなので構造上一致 | 行の帯で頂点を共有 + 曲線補間 + Taubin |
| 行の配置 | 密度を積分した均等配分、平面で切る | 弧長 + 毛先寄せ |
| 分岐 | トランクと合流壁 | パラメータで自動分割 |
| VRM向け | UVは手動(Topology画面) | UV・物理用頂点グループ・法線・三角形数 |

## 7. 取り入れる候補(価値 ÷ 手間の順)

1. **密度を積分した均等配分**:曲がり・毛先・ガイドの密度に応じてループを配る。手間が小さい
2. **共通のループ平面で行を切る**:グループ共通のスパイン平面で各房を切り、行を自動で一致させる。行がずれる問題をなくせる
3. **縁カーブモード**:房を2本の縁カーブの間の直線織面 + 膨らみで作り、隣とカーブを共有する。中心線 + 幅の房は縁カーブに変換できる
4. **折れの検出と行の挿入**:手間が小さい
5. **徐々に細くする毛先**:列統合による毛先の三角形化
6. **溶接パス**:空間ハッシュ、埋もれた面の削除、穴埋め
7. **つむじ用のメッシャー**:効果は大きいが手間も大きい
8. **ループのプレビュー表示**と**つながりの診断**

## 8. HairHarpy の溶接(詳細調査)

読んで研究しただけです。コードのコピーはしていません。

### 3段構え
1. **上流での共有**(位置の一致を保証するのはここだけ)
   - アンカーとカーブを共有し、共有区間では接線を平均する(G1連続)。
   - 分岐点で、ネットワークを分割する(Y字の分岐を幹に沿って延長し、重なる区間は1本の幹にまとめる)。
   - 子の房は、親の輪切りの平面をそのまま受け継ぐ。同じ平面で同じカーブを切るので、頂点の位置がビット単位で一致する。
2. **房ごとのメッシュ化**
   - 輪切りの平面と各列の交点をつないで輪郭を作る(2Dグラフの外周を反時計回りの最小回転でたどる)。
   - 8の字やリボンにも対応している。
   - 隣の輪郭とは列キーの最長共通部分列(LCS)でつなぐ。列数が違うところは、最短の辺に三角形を置いて吸収する。
   - 1→2 の分岐は、輪郭を A/B の2本の弧に分けて、股のクワッドを1枚置く。それが無理なら、2つの輪郭を橋渡しして1つにする。
   - 折れを検出したら輪切りを挿入する(30°超、かつ間隔が幅の1.5倍超。最大3回)。
3. **後から修復して報告**
   - 0.1h で近い頂点を union-find でまとめる。先に処理した親の位置に合わせ、同じ房の頂点同士はまとめない。
   - 二重になった壁は両方削除する。相手の房の中に埋もれた面は、レイの偶奇判定を3方向の多数決で行って削除する。
   - 16辺以下の穴を埋める。面の向きはBFSでそろえる。
   - 残った問題(穴が開いている / 3面以上が接する辺 / 少しずれた共有 / 離れている)は「Check connections」に赤で表示する。
   - AutoFix は「試して、検証して、ダメなら戻す」方式。
   - **多様体であることや、全部クワッドであることは保証していない**。最後の多様体化で、裂け目が残ることがある。

### 得意なもの / 苦手なもの
- **得意**:幹を共有するY字や多分岐、横並びの共有、途中からの分岐、8の字断面、リボン、親子の連鎖
- **苦手(報告に頼る)**:
  - カーブを共有しない交差や重なり
  - 3枚以上の面が接する辺
  - 少しずれた共有の壁
  - 関係のない房同士(溶接されない)
  - 斜めになった平面の継承
  - 細かいカールや折れ

### Toon Hair Studio との比較
- **HairHarpy にしかできないこと**:
  - 行数や長さの違う房同士の接合
  - 列数の違う房の接合
  - X字・3方向以上の合流、任意のネットワーク
  - グループをまたぐ接合
  - 重なりの修復と、接続のチェック・自動修正
- **Toon Hair Studio が勝っているところ**:
  - 構造化されたクワッドの格子(修復が要らず、位相が決まっている)
  - 一貫した UV
  - Catmull-Rom の継ぎ目による折れない合流
  - 切れ込みがなめらかに開く遷移
  - 厚みの補間と Taubin スムージング
  - 速い

### 取り入れる計画(優先順、独自実装)
1. **汎用の溶接・後処理パス**:kdtree で近い順に union-find(安全ルール付き)→ 二重の面と埋もれた面の削除 → 小さな穴の埋め → 面の向きの統一。グループ間や、層の重なりの安全網にする。
2. **平面を共有する行**:手動でつないだペアで、基準の房の行の平面を相手の中心線と交差させる。長さや層が違っても、行を一致させられる。
3. **接続チェッカーのUI と AutoFix**
4. **折れ検出と行の挿入**
5. **LCS でのつなぎ**:グループ間で列数が違う場合に限る
6. **鎖からグラフへの一般化**:X字・3方向以上の合流
