# 06. 椅子マット（SeatPad）v0 製作ガイド（座面＋背もたれ・汎用サイズ）

> 目的：普通の椅子（ダイニングチェア〜オフィスチェア）に置ける、座面と背もたれの圧力マットを自作する。
> 回路はユニバーサル基板で組める部品（DIP 中心）で構成。ファームウェアは `firmware/pressure_pad/`（床マットと共通）、PC ツールは `tools/pressure_pad/`。床マットは [07](07_floorpad_v0_build_guide.md)。
> 部品の価格は概算。部品の型番の細部（ピン配置・入力しきい値）は必ず各データシートで確認すること。

---

## 1. 仕様

| 項目 | 座面（SEAT） | 背もたれ（BACK） |
|---|---|---|
| 有効エリア | **38.4 × 38.4cm** | **32.0 × 31.2cm**（幅×高さ） |
| 外形（余白込み） | 約 42 × 42cm | 約 35 × 34cm |
| マス目 | 16行 × 16列 = 256点 | 12行 × 16列 = 192点 |
| ピッチ | 2.4cm（電極幅 1.6cm、隙間 0.8cm） | 列 2.0cm（幅 1.4 / 隙間 0.6）、行 2.6cm（幅 1.8 / 隙間 0.8） |
| 想定する椅子 | 座面が 40cm 角以上ならほぼ載る | 背もたれの幅が 33cm 以上。腰の位置（座面から約 10cm 上）から肩甲骨の下まで |
| 向き | 行0 = 後ろの縁（背もたれ側）、列0 = 着席者の左 | 行0 = 下（腰）、列0 = 着席者の左 |

- **全448点を 60Hz で読み取り**（1フレームの読み取りは約 7ms）。
- 座面と背もたれは**列の16本を共有**し、読み取り回路は1組で済む。背もたれは外してもよい（未接続ならすべて 0 になるだけ）。
- サイズの根拠：着席時の腰幅は大柄な人で 40cm 強、左右の坐骨の間隔は 10〜13cm（2.4cm ピッチで 4〜5マス）。ダイニングチェアの座面（約 40cm 角）にも載るよう、有効エリアは 38.4cm に抑えた。

## 2. 読み取りの原理（ゼロ電位法）

```
            Vb(1.65V)                          3.3V
              │ 2.2kΩ プルアップ（全行）        │
   行 r ──────┼──────┬───────┬─────...       ┌─┴─┐
              │      │セル    │セル            │TIA│ 出力 = Vb + I·Rf ──▶ 4067 ──▶ ADC0
   TBD62083 ──┘      │        │                │   │
   (選択行だけ GND)  列0 ─────┼────────────────▶│ − │ (+入力 = Vb、帰還 Rf=1kΩ ∥ 470pF)
                             列1 ...            └───┘ ×16
```

- 全列は TIA（オペアンプによる電流→電圧変換）で常に **Vb に固定**。
- 選択していない行もプルアップで **Vb**。両端が同じ電圧なので、**選択行以外のセルには電流が流れない** → ゴースト（回り込み）がほぼ出ない。
- 選択した行だけドライバーで GND に落とす → そのセルの電流 `I = Vb × G`（G = セルの導電率）が TIA で電圧になる。
- つまり **`(ADC値 − Vb の ADC値)` がセルの導電率に比例**する。Velostat の導電率は荷重にほぼ比例して増えるので、扱いやすい。

## 4. マットの作り方

### 4.1 層の構成（下から）

```
  滑り止めシート / 外カバー
  ── 土台布 A（リップストップ）＋ 行電極（導電布テープ、左右方向）
  ── Velostat（1枚。有効エリアより各辺 1cm 大きく）
  ── 土台布 B（リップストップ）＋ 列電極（導電布テープ、前後方向）  ← 電極面を下向きに
  外カバー（薄い布）
```

### 4.2 手順
1. 土台布 A・B を外形に切り、**チャコペンで電極の位置を描く**（座面：2.4cm ピッチで幅 1.6cm の線を 16本。背もたれは §1 の寸法）。
2. 導電布テープを線に沿って貼る。**端は有効エリアから 2cm はみ出させる**（配線をつなぐため）。テープ同士が触れていないか、テスターで隣同士の導通がないことを確認。
3. Velostat を A の電極面に載せ、外周だけを布用両面テープで留める。**有効エリア内は接着しない**（接着剤の厚みで感度がばらつくため）。
4. B を電極面が下になるようにかぶせ、外周を両面テープで留める。行と列が直交していることを確認。
5. **配線**：フラットケーブル（16芯）の一端に IDC ソケットを圧着し、もう一端を1本ずつ裂いて被覆を 1cm むく。むいた芯線を電極のはみ出し部分に載せ、**上から導電布テープの小片（2cm）で押さえて貼る** → さらにカプトンテープで覆う。ケーブルは外周に沿わせて布テープで固定し、根元に余裕（ストレインリリーフ）を持たせる。
   - ケーブルの芯線1番 = 行0（または列0）。座面の行は左側の縁、列は後ろの縁から出る。
6. 外カバーをかぶせる。座面は下に滑り止めシート、背もたれはゴムバンドか面ファスナーで背もたれに巻く（メッシュの背もたれは裏に薄いプラダンを当てる）。

### 4.3 Velostat を継ぎ合わせる場合
28cm 角のシートしか手に入らないときは、**継ぎ目が電極の隙間（座面なら 0.8cm 幅）に来るように**突き合わせ（重ねない）、継ぎ目の上をカプトンテープで留める。

## 5. 回路の接続表

### 5.1 Pico のピン

| Pico | 接続先 |
|---|---|
| GP2 | U1–U4 の SRCLK（11番ピン）すべて |
| GP3 | U1 の SER（14番ピン） |
| GP7 | U1–U4 の RCLK（12番ピン）すべて |
| GP10–GP13 | 4067 の S0–S3 |
| GP26（ADC0） | 4067 の SIG |
| GP27（ADC1） | Vb レール（1kΩ を直列に入れる） |
| GP4 / GP5 | 予約（将来の IMU 用 I2C） |
| 3V3(OUT) | 3.3V 電源（595、4067、オペアンプ、TBD の COM） |
| GND | GND |

GP23 は Pico 基板内部の電源モードの切り替え。ファームウェアで HIGH にして ADC のノイズを減らす（配線は不要）。

### 5.2 行の駆動（U1–U8、RN1–RN4）
- 74HC595：VCC=3.3V、GND、**OE（13番）→ GND、SRCLR（10番）→ 3.3V**。U1 の QH'（9番）→ U2 の SER、U2→U3、U3→U4 と数珠つなぎ。
- 595 の出力 → TBD62083 の入力：U1 の QA–QH（15, 1–7番）→ U5 の IN1–IN8、U2→U6、U3→U7、U4 の QA–QD → U8 の IN1–IN4。
- TBD62083：GND、**COMMON → 3.3V**（内蔵のクランプダイオードが Vb 側で導通しないように）。OUTn は INn に対応（**ピン番号は逆順なのでデータシートの図で確認**）。
- 行の割り当て：U5 の OUT1–8 → J1 の 1–8番（座面の行 0–7）、U6 → J1 の 9–16番（座面の行 8–15）、U7 → J3 の 1–8番（背もたれの行 0–7）、U8 の OUT1–4 → J3 の 9–12番（背もたれの行 8–11）。
- 各行に 2.2kΩ のプルアップ（集合抵抗の共通端子 → Vb）。

### 5.3 列の読み取り（U9–U14）
- J2（座面の列）と J4（背もたれの列）の同じ番号のピンを**基板上で並列に接続** → 列 0–15。
- 列 j → オペアンプの −入力。+入力 → Vb。出力と −入力の間に **Rf（1kΩ）と Cf（470pF）を並列**。
- オペアンプの電源：3.3V / GND。各 IC の電源ピンの近くに 0.1µF のパスコン。
- オペアンプの出力 j → 4067 の Cj。4067：VCC=3.3V、EN→GND。

### 5.4 Vb（1.65V）の生成（U13）
- 3.3V –10kΩ– ノード –10kΩ– GND、ノードに 0.1µF → MCP6002 の A 側の +入力。A 側はボルテージフォロワ（出力 → −入力）。
- 出力 → **22Ω** → Vb レール（10µF ＋ 0.1µF）。帰還はオペアンプの出力ピン側からとる（大きな容量で発振させないため）。
- Vb レール → 全オペアンプの +入力、RN1–RN4 の共通端子、1kΩ を経由して GP27。
- MCP6002 の B 側は、+入力 → GND、出力 → −入力 にして処理しておく。

## 6. 立ち上げとテスト

1. **ファームウェアを書き込む**：Arduino IDE で「Raspberry Pi Pico/RP2040」（Earle F. Philhower 版）のボードを追加 → `firmware/pressure_pad/pressure_pad.ino` を開き、先頭の `#define BOARD` を `BOARD_PICO_DIY` に、`#define PAD_KIND` を `PAD_CHAIR` にして書き込む（部品付きプリント基板の場合は [09](09_pcb_order_guide.md)）。
2. **PC ツール**：
   ```
   cd tools/pressure_pad
   pip install -r requirements.txt
   python viewer.py --fake chair      # 実機なしで表示を確認
   python viewer.py --port COM5       # Windows（デバイスマネージャーで番号を確認）
   ```
3. **マットなしで確認**：全セルがほぼ 0（ノイズ程度）。`Vb` の ADC 値が約 2048 になっていること。
4. **抵抗で1点テスト**：J1 の 4番（座面の行 3）と J2 の 6番（座面の列 5）の間に 4.7kΩ をつなぐ → **行3・列5 だけが約 210µS** で光れば、配線・行と列の対応・計算式がすべて正しい。他の点が光るなら配線ミス。
5. **Rf の決定**：マットを敷いて座り、テスターで「坐骨の真下」の行と列の間の抵抗を測る（他のセルを通る経路があるので実際より低めに出る＝安全側）。その最小値の **0.7倍程度を Rf にする**。Rf がセルの抵抗より大きいと飽和して、画面に `SATURATED` と出る。
   - 最小値が 300Ω を切るほど低い → Velostat を2枚重ねにする、または電極を細くする。
   - Rf を変えたら `--rf` で値を指定：`python viewer.py --port COM5 --rf 680`
6. **ゼロ点の取得**：椅子から立って `z` キー → 30フレームの平均を無荷重の基準として引く。マットを付け直したとき・背もたれを曲げて付けたときは毎回行う。
7. **記録**：`r` キーで開始・停止 → `recordings/chairpad_日時.npz`（生の ADC 値、デバイスの時刻、PC の受信時刻、時刻合わせの PING/PONG）。

## 7. 既知の制限（v1 で改善する点）

| 制限 | 影響 | v1 での対策 |
|---|---|---|
| TIA が飽和すると、その列の電圧が Vb からずれる | 強く押したセルの列で、他の行にわずかな回り込み | Rf を適切に選ぶ。v1 はゲイン切り替え |
| 行ドライバーのオン抵抗（約 2Ω）による電圧降下 | 行ごとにわずかなゲイン誤差 | PC 側で補正済み（`Electrical.row_driver_ohm`）。v1 は低オン抵抗の MOSFET |
| Pico の内蔵 ADC の非線形性（特定コード付近の段差） | 細かい値に誤差 | 正規化と学習で吸収。v1 は外部 ADC |
| 布＋ Velostat のクリープ・ヒステリシス | 長時間でずれる | 離席ごとのゼロ点更新、材料の比較（02 §4.2） |
| 芯線を導電布テープで貼る接続 | 曲げに弱い可能性 | v1 はマット専用のフレキ基板のテール＋コネクタ |
| IMU なし | 椅子の回転が分からない | GP4/GP5 に 6軸 IMU を追加（v0.1） |
