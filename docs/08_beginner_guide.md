# 08. はじめての製作ガイド（電子工作が初めての人向け）

> 06（椅子マット）・07（床マット）を、電子工作の経験がない人でも進められるように、**順番どおりに・一歩ずつ**書いた手順書です。
> 分からない言葉は「付録A 用語ミニ辞典」を見てください。

---

## 0. 全体の流れ

いきなり本番を作ると、動かなかったときにどこが悪いのか分かりません。**小さく作って確かめてから大きくする**順番で進めます。

| ステップ | やること | はんだ付け | 目安の時間 |
|---|---|---|---|
| 1 | 道具と部品をそろえる | — | 注文して数日 |
| 2 | パソコンの準備（ソフトのインストール） | なし | 1時間 |
| 3 | Pico にプログラムを書き込む | なし | 30分 |
| 4 | **練習回路**をブレッドボードで組む（4×4 = 16点） | なし | 半日 |
| 5 | **練習マット**（手のひらサイズ）を作って測る | なし | 2時間 |
| 6 | はんだ付けの練習 | あり | 1〜2時間 |
| 7 | 本番のマットを作る（椅子・床） | なし | 1日 |
| 8 | 本番の基板を作る（ブロックごとに作って確認） | あり | 2〜3週末 |
| 9 | つないで動かす | — | 1時間 |

ステップ4〜5 の練習回路は、**本番の回路をそのまま小さくしたもの**です。ここで動けば、本番は「同じものを数を増やして作る」だけになります。

> **ステップ8 について**：本番の基板はつなぐ場所が多く（椅子用で約 350か所）、初めてだと大変です。**プリント基板を業者に発注し、部品を付けた状態で届けてもらう**方法もあります（設計データが必要なので、その場合は相談してください）。ステップ7までは、どちらの方法でも同じです。

## 2. パソコンの準備（Windows の場合）

### 2.1 このプロジェクトのファイルを手に入れる
1. ブラウザで GitHub のこのリポジトリ（`lionjazz15-cpu/Pictures`）を開く。
2. 左上のブランチ選択で **`ccr-19c0a293-fsx4w0`** を選ぶ。
3. 緑の「**Code**」ボタン →「**Download ZIP**」→ ダウンロードした ZIP を右クリック →「すべて展開」。
4. 展開したフォルダを、分かりやすい場所（例：`ドキュメント\ChairMotion`）に置く。

### 2.2 Arduino IDE（Pico にプログラムを書き込むソフト）
1. 「Arduino IDE」で検索して公式サイトから **Arduino IDE 2** をダウンロード・インストール。
2. 起動して、メニュー「ファイル」→「基本設定」→「**追加のボードマネージャの URL**」に次を貼り付けて OK：
   ```
   https://github.com/earlephilhower/arduino-pico/releases/download/global/package_rp2040_index.json
   ```
3. 左の「ボードマネージャ」（ボードの形のアイコン）で **`pico`** と検索 →「**Raspberry Pi Pico/RP2040/RP2350**（作者 Earle F. Philhower）」を「インストール」。数分かかります。

### 2.3 Python（パソコン側の表示ツールを動かすソフト）
1. 「python.org」から Windows 用のインストーラ（3.12 以降）をダウンロード。
2. インストール画面の最初で **「Add python.exe to PATH」にチェックを入れてから** 「Install Now」。
3. エクスプローラーで `ChairMotion\tools\pressure_pad` フォルダを開き、上のアドレス欄に `powershell` と入力して Enter → 青い画面（PowerShell）が開く。
4. 次を入力して Enter（必要なライブラリが入ります）：
   ```
   py -m pip install -r requirements.txt
   ```
5. 動作確認（部品がなくても動く「お試しモード」）：
   ```
   py viewer.py --fake test
   ```
   4×4 のマス目が順番に光るウィンドウが出れば OK。`--fake chair`、`--fake floor` も試せます。閉じるときは `q` キー。

## 3. Pico にプログラムを書き込む

1. Arduino IDE で「ファイル」→「開く」→ `ChairMotion\firmware\pressure_pad\pressure_pad.ino` を開く。
2. 上のほうにある次の行を、**練習用の `PAD_TEST` に書き換える**：
   ```
   #define PAD_KIND PAD_TEST  // <- change to PAD_FLOOR / PAD_TEST
   ```
3. 「ツール」→「ボード」→「Raspberry Pi Pico/RP2040/RP2350」→「**Raspberry Pi Pico**」を選ぶ。
4. **初回だけ**：Pico の白いボタン「**BOOTSEL**」を押したまま USB ケーブルをパソコンに挿し、挿したらボタンを離す（Pico が USB メモリのように見える状態になる）。
5. Arduino IDE の「ツール」→「ポート」で「UF2 Board」などを選び、左上の「→」（書き込み）ボタンを押す。
6. 「書き込み完了」と出たら成功。2回目以降は BOOTSEL なしで書き込めます（ポートは「COM○（Raspberry Pi Pico）」を選ぶ）。

**動作確認**：Arduino IDE の右上の虫眼鏡アイコン（シリアルモニタ）を開き、下の欄の右側の設定を「**改行（LF）**」にして、`INFO` と入力して Enter。
`#INFO {"fw":"pressure_pad_v0","kind":"test",...}` と返ってくれば、Pico は正常に動いています。
（まだ何もつないでいないので、`DUMP` と入力すると意味のない数字が出ますが、問題ありません）

> **シリアルモニタは使い終わったら必ず閉じる**。開いたままだと、表示ツール（viewer.py）が Pico とつながりません。

## 4. 練習回路をブレッドボードで組む（はんだ付けなし）

### 4.1 始める前の約束
- **配線中は USB を抜いておく**。配線が終わって、確認してから挿す。
- **IC の向きに注意**：IC の上面には半円の切り欠き（またはくぼみの点）があり、その左下が **1番ピン**。上から見て、1番から**反時計回り**に番号が増える。
  ```
        切り欠き
     ┌───╮╭───┐
   1 ┤        ├ 16
   2 ┤        ├ 15
   3 ┤ 74HC595├ 14
   …  …      …
   8 ┤        ├ 9
     └────────┘
  ```
- IC は、ブレッドボード中央の溝をまたぐように挿す（左右の足が別々の列に入るように）。
- 迷ったら、**部品のデータシート（型番 + datasheet で検索）のピン配置図**で確認する。

### 4.2 ブレッドボードの使い方（30秒で）
- 中央の溝をはさんで、**縦に並んだ5つの穴は中でつながっている**。
- 上下の端にある長い列（赤＋・青−の線）は**電源用のレール**で、横一列がつながっている（製品によっては真ん中で切れているので、テスターで確認）。
- この回路では、レールを次のように使う：

| レール | 用途 |
|---|---|
| 赤（＋） | **3.3V**（Pico の 36番ピンから） |
| 青（−） | **GND**（Pico の 38番ピンから） |
| 2枚目の上側の赤レール | **Vb（1.65V）**。紙に「Vb」と書いて貼っておく（3.3V と間違えないため） |

### 4.3 部品の配置

```
 ブレッドボード1                                   ブレッドボード2
 ┌─────────────────────────────────────────┐   ┌─────────────────────────────────────────┐
 │ [Pico]       [74HC595]   [TBD62083]     │   │ [MCP6002]  [MCP6004]   [4067 モジュール] │
 │  USBは左向き   (U1)        (U5)          │   │  (Vb作成)   (TIA×4)                     │
 └─────────────────────────────────────────┘   └─────────────────────────────────────────┘
   行(row)の線はTBD62083から出る                  列(col)の線はMCP6004に入る
```

### 4.4 配線表

Pico のピン番号は、**基板の裏の印字**（または「Pico pinout」で検索した図）で確認します。USB 端子を上にして、左上が1番、左下が20番、右下が21番、右上が40番です。

| ブレッドボード1 と 2 の赤レールどうし、青レールどうし | ジャンパーでつなぐ |

| MCP6002 4番（VSS） | GND |

| 10kΩ | 分圧点 と GND の間 |

### 4.5 電源を入れる前のチェック（毎回やる）
1. USB を抜いた状態で、テスターを導通ブザーにして、**3.3V レールと GND レールの間で鳴らない**ことを確認（鳴ったらどこかでショートしている）。
2. **Vb レールと 3.3V、Vb レールと GND** の間でも鳴らないこと。
3. IC の向き（切り欠き）をもう一度確認。

### 4.6 抵抗1本で動作テスト
1. **4.7kΩ の抵抗を、行1 と 列2 の間に挿す**（＝「行1・列2」のマスを、4.7kΩ のセンサーに見立てる）。
2. USB を挿し、PowerShell で（`COM5` は Arduino IDE の「ツール」→「ポート」に出ている番号に変える）：
   ```
   py viewer.py --port COM5
   ```
3. **行1・列2 のマスだけが光り、下の行に「約 4700 ohm」**と出れば大成功。ここまで動けば、回路の考え方・配線・プログラム・計算がすべて正しいということです。
4. 違うマスが光る → 行か列の線の入れ違い。全部 0 → ③の HOLD 確認に戻る。

## 5. 練習マット（4×4）を作って、Velostat を測る

### 5.1 作り方
1. 厚紙を 15cm 角に2枚切る（A、B）。
2. A に、**導電布テープ（幅 2cm）を 4本、横向きに**貼る。長さは 15cm、テープどうしの**隙間は 1cm**。紙の右端から 2cm はみ出させる（配線をつなぐ場所）。
3. B にも同じように 4本、**縦向き**に貼る（下端から 2cm はみ出させる）。
4. テスターの導通ブザーで、**隣どうしのテープが鳴らない**ことを確認。
5. A のテープ面の上に Velostat（12cm 角）を置き、その上に B をテープ面を下にしてかぶせる。**外周だけ**をマスキングテープで留める。
6. ジャンパーワイヤー（オス）の片方の先を、はみ出したテープの端に乗せ、上から**導電布テープの小片で押さえて貼る**。A の4本を行0〜3、B の4本を列0〜3 として、ブレッドボードの行・列の線につなぐ（4.6 の 4.7kΩ は外す）。

### 5.2 測る
1. `py viewer.py --port COM5` で表示。
2. 指で押す → 押したマスが光る。手のひら全体で押す、**練習マットの上に座る**（坐骨の下に来るように）、**座ったまま、かかとで踏む**（床マット用）。
3. 下の行に出る「**ohm**」の値をメモする。**座ったときの一番小さい値**が、本番の部品（Rf）を決める材料になる。
   - この測定のときは **`z`（ゼロ点）を押さない**。押すと「何も乗っていないときの分」が差し引かれて、実際より大きい値が出るため（押してしまったら、ウィンドウを閉じて開き直す）。
4. 見た目を確かめるときは、何も乗せない状態で `z` を押すと、押したところだけがはっきり光るようになる。

| 測ったときの最小値 | 本番の Rf（椅子マット） |
|---|---|
| 1,500Ω 以上 | 1kΩ のまま |
| 700〜1,500Ω | 470Ω |
| 300〜700Ω | 220Ω |
| 300Ω 未満 | Velostat を2枚重ねにして測り直す |

床マットも同じように、「かかとで踏んだときの最小値」の 0.7倍程度を目安にします（足の圧力は座面より弱いので、多くの場合 2.2〜4.7kΩ になります）。
画面に `SATURATED` が出たら、Rf が大きすぎる（値が振り切れている）合図です。

## 6. はんだ付けの練習

1. こての温度：鉛入りはんだなら **340℃前後**、鉛フリーなら **360〜370℃**。
2. **換気**をする。こては必ずこて台に置く。先端は 300℃以上なので絶対に触らない。
3. 手順：**① こて先を「部品の足」と「基板の銅の輪（ランド）」の両方に当てて 1〜2秒温める → ② はんだを当てて溶かす（こてではなく、温まった部分に当てる） → ③ はんだを離す → ④ こてを離す**。全部で 3〜4秒。
4. 良いはんだ付けは、**富士山のような形で、つやがある**。丸い玉になっている・灰色でざらざらしている場合は、温め不足なのでやり直す。
5. 余ったユニバーサル基板と抵抗で、**20か所くらい練習**してから本番に進む。4067 モジュールのピンヘッダ付けは、ちょうどいい練習になる。

## 7. 本番のマットを作る

寸法は 06 §1（椅子）・07 §1（床）にあります。基本は練習マットと同じで、**大きくて本数が多いだけ**です。

### 7.1 きれいに貼るコツ：隙間ゲージを作る
- 厚紙を**隙間の幅**（座面なら 0.8cm、背もたれの列なら 0.6cm、床の列なら 1.0cm）で細長く切り、「隙間ゲージ」にする。
- 1本目のテープを定規に沿って貼る → ゲージを当てる → ゲージに沿って2本目を貼る……と繰り返すと、測らなくても等間隔になる。
- テープは**端から少しずつ**、指やスプーンの背でこすって空気を抜きながら貼る。しわは感度ムラの原因。

### 7.2 手順
1. 土台の布（リップストップ）を外形どおりに切る。座面・背もたれ・床で、それぞれ2枚ずつ（行用・列用）。
2. 行用の布に行の電極、列用の布に列の電極を貼る。**端は 2cm はみ出させる**。
3. **全部の隣どうしで、テスターが鳴らないことを確認**（ここで見つけたショートは簡単に直せる。組み立てた後だと大変）。
4. Velostat を置き、もう1枚をかぶせて、外周を布用両面テープで留める（中は接着しない）。
5. **配線**：16芯のフラットケーブルの片側に IDC ソケットを付ける（ソケットにケーブルを挟み、万力かペンチで**まっすぐ均等に**押しつぶす。赤い線の側が1番ピン）。反対側を 1本ずつ 5cm ほど裂き、先の被覆を 1cm むいて、電極の端に乗せ、**導電布テープの小片で押さえ、その上をカプトンテープで覆う**。
   - ケーブルの1番目の線 = 行0（または列0）。順番を間違えないよう、**1本つなぐたびにテスターで「IDC ソケットの穴」と「電極」の間が鳴るか確認**。
6. ケーブルを外周に沿わせて布テープで固定し、根元に少し余裕を持たせる（引っ張られても電極からはがれないように）。
7. 椅子：座面は上にカバー・下に滑り止め。背もたれはゴムバンドで巻く。床：上に EVA フォーム、カーペットなら下に薄い板。

## 8. 本番の基板を作る（ブロックごとに作って、確認してから次へ）

本番の回路は**練習回路と同じ構成**で、数が増えるだけです（椅子用は 74HC595 と TBD62083 が4個ずつ、MCP6004 が4個、TIA が16組）。ユニバーサル基板に、**1ブロック作るたびに確認**しながら進めます。

### 8.1 配置の例（160×100mm 程度のユニバーサル基板）

```
 ┌──────────────────────────────────────────────────────────────┐
 │ [J1 座面の行] [J3 背もたれの行]          [J2 座面の列] [J4 背もたれの列] │
 │                                                              │
 │ [U5 TBD][U6 TBD][U7 TBD][U8 TBD]      [U9 6004][U10 6004]      │
 │ [RN1][RN2][RN3][RN4]                   [U11 6004][U12 6004]     │
 │ [U1 595][U2 595][U3 595][U4 595]       [4067 モジュール]         │
 │                                                              │
 │ [Pico]                   [U13 MCP6002 と Vb 部品]              │
 └──────────────────────────────────────────────────────────────┘
   ↑ 電源（3.3V・GND）はスズメッキ線で基板の上下に太い「レール」を作る
```

- IC は直接はんだ付けせず、**IC ソケット**をはんだ付けしてから挿す（向きの間違い・故障時に交換できる）。
- 電源（3.3V、GND、Vb）は**スズメッキ線**で基板の端から端まで通す。信号の線は**ポリウレタン線（UEW）**（被覆をむかずに、はんだの熱で被覆が溶ける細い線）か、細いビニール線を使う。
- 行の集合抵抗（RN）は、**共通端子（印のある1番ピン）を Vb** につなぐ。

### 8.2 作る順番と確認（練習回路と同じ確認方法）

| ブロック | 作るもの | 確認方法 |
|---|---|---|
| A | Pico のソケット、3.3V と GND のレール | USB を挿す前に、3.3V–GND 間でブザーが鳴らないこと |
| B | Vb を作る部分（U13 まわり） | Vb が 1.6〜1.7V |
| C | 行の駆動（U1〜U8、RN1〜RN4、J1/J3 への配線） | `HOLD 0`〜`HOLD 27` で、選んだ行だけ 0V（J1/J3 のピンで測る） |
| D | 列の読み取り（U9〜U12、Rf・Cf ×16、4067、J2/J4 への配線） | 4.7kΩ を J1 の 4番と J2 の 6番の間につなぎ、`DUMP` で行3・列5 だけ数字が大きいこと |
| E | 全部の確認 | 4.7kΩ を、いろいろな行・列の組み合わせに付け替えて、そのマスだけが光ること |

**1本はんだ付けするたびに、配線表を印刷した紙に蛍光ペンで印を付ける**と、付け忘れ・二重付けを防げます。配線表は 06 §5 にあります。

床マット用の基板は、U3/U4・U7/U8・RN3/RN4・J3/J4 を付けないだけで、同じ手順です。

## 9. つないで動かす

1. Arduino IDE で `pressure_pad.ino` の `PAD_KIND` を **`PAD_CHAIR`**（椅子用の Pico）または **`PAD_FLOOR`**（床用の Pico）に書き換えて、それぞれ書き込む。
2. 練習で決めた Rf を基板に付けておく。
3. マットのケーブルを基板の J1〜J4 に挿す（ソケットの向きに注意。赤い線が1番ピン側）。
4. `py viewer.py --port COM5`（椅子）／ `py viewer.py --port COM6`（床）。Rf を 1kΩ 以外にした場合は `--rf 470` のように付け足す。
5. 誰も乗っていない状態で `z` → 座る・足を置く → 画面が反応すれば完成。`r` キーで記録できます。

## 10. 困ったとき

| 症状 | 考えられる原因 | 対処 |
|---|---|---|
| パソコンが Pico を認識しない | 充電専用ケーブル | データ通信用のケーブルに替える |
| 書き込みできない | ポートの選択違い | BOOTSEL を押しながら挿し直し、「UF2 Board」を選ぶ |
| `no frames received` と出る | ポート番号が違う／**シリアルモニタが開いたまま** | Arduino IDE のポート表示で番号を確認。シリアルモニタを閉じる |
| `DUMP` の `vb=` が 2048 から大きくずれる | Vb の部分の配線 | §4.4 ② を見直す。Vb レールを測る |
| 全部のマスが 0 | 行が駆動されていない | `HOLD` で行の電圧を確認。TBD の COMMON・595 の OE（13番）を確認 |
| 特定の行・列だけ反応しない | その線の配線・電極との接触 | ブザーで IDC ソケット〜電極を確認 |
| 1列（または1行）全体が光る | 隣の電極どうしのショート、TIA の配線ミス | マットの隣どうしをブザーで確認 |
| `SATURATED` が出る | Rf が大きすぎる | Rf を小さくする（§5.2 の表） |
| 値がふらふらする | ケーブルが長い・パスコン不足 | 各 IC の近くに 0.1µF があるか確認。ケーブルを短く |
| 時間がたつと値がずれる | Velostat の性質（クリープ） | 立ち上がって `z` を押し直す |
| IC や部品が熱い | 逆挿し・ショート | **すぐ USB を抜く**。向きと配線を確認 |

## 付録A 用語ミニ辞典

| 用語 | 意味 |
|---|---|
| Pico（Raspberry Pi Pico） | 小さなコンピューター（マイコン）の基板。センサーを読んでパソコンに送る係 |
| IC | 黒くて足がたくさん生えた部品。中に回路が入っている |
| DIP | 足が2列に並んだ、ブレッドボードに挿せる形の IC |
| ブレッドボード | 穴に部品を挿すだけで回路が組める板。はんだ付け不要 |
| ユニバーサル基板 | 穴がたくさん開いた板。部品をはんだ付けして回路を作る |
| はんだ付け | 熱で溶かした金属（はんだ）で、部品と基板をくっつけること |
| テスター | 電圧や、つながっているかどうかを測る道具 |
| 導通 | 電気的につながっていること。テスターのブザーが鳴る |
| ショート | つながってはいけない所がつながること。故障の原因 |
| GND（グラウンド） | 電圧の基準（0V）。回路全体で共通 |
| 3.3V | Pico が作る電源の電圧 |
| Vb | この回路で作る 1.65V の基準電圧（3.3V の半分） |
| 抵抗（Ω） | 電気の流れにくさ。色の帯で値が分かるが、**迷ったらテスターで測るのが確実** |
| コンデンサ | 電気を一時的にためる部品。電圧を安定させる。10µF の電解コンデンサには ＋−の向きがある |
| オペアンプ | 小さな信号を扱いやすくする IC。ここでは電流を電圧に変える（TIA） |
| TIA | トランスインピーダンスアンプ。センサーに流れた電流を電圧に変える回路 |
| マルチプレクサ（4067） | 16本の線から1本を選んで Pico に渡す切り替えスイッチ |
| シフトレジスタ（74HC595） | Pico からの少ない線で、たくさんの出力を切り替える IC |
| ドライバー（TBD62083） | 選んだ行を GND につなぐスイッチの役 |
| Rf | TIA の抵抗。センサーの感度の範囲を決める |
| Velostat | 押すと電気が流れやすくなる黒いシート。センサーの本体 |
| 導電布テープ | 電気が流れる布のテープ。マットの電極（行・列の線）にする |
| IDC ソケット／フラットケーブル | 平たい多芯ケーブルと、それを基板のピンに挿すコネクタ |
| シリアルモニタ | Arduino IDE で、Pico と文字でやりとりする画面 |
| ゼロ点（`z`） | 何も乗っていない状態を「0」として覚えさせること |
