# 07. 床マット（FloorPad）v0 製作ガイド

> 目的：机の下の床に敷き、**足の接地（左右・かかと／つま先）と、床に着いている足の位置**を実測する。
> 回路・ファームウェア・PC ツールは椅子マット（[06](06_seatpad_v0_build_guide.md)）と共通。この文書は**違う点だけ**を書く。

## 1. 仕様

| 項目 | 値 |
|---|---|
| 有効エリア | **幅 60 × 奥行き 48cm**（机の下の、足を置く範囲） |
| 外形（余白込み） | 約 64 × 52cm |
| マス目 | 16列 × 16行 = 256点 |
| ピッチ | 列（左右）3.75cm（電極幅 2.75 / 隙間 1.0）、行（前後）3.0cm（電極幅 2.2 / 隙間 0.8） |
| 向き | 行0 = 椅子側の縁、列0 = 着席者の左 |
| 読み取り | 60Hz（1フレームの読み取りは約 4ms） |
| 接続 | **椅子マットとは別の Pico・別の USB**（椅子は回転・移動するので、椅子と床をケーブルでつながない） |

サイズの根拠：足の長さは約 25cm、普通に座ったときの両足の間隔（中心どうし）は 15〜40cm。前後 48cm あれば、足を引いた位置から前に出した位置まで入る。ピッチ 3cm で、かかと・土踏まず・つま先が別々のマスに分かれる。

## 2. 椅子マットとの違い

| 項目 | 椅子マット（06） | 床マット |
|---|---|---|
| 行ドライバー | 74HC595 ×4、TBD62083 ×4、集合抵抗 ×4 | **それぞれ ×2**（U1/U2、U5/U6、RN1/RN2 のみ実装） |
| コネクタ | J1–J4 | **J1（行）・J2（列）のみ** |
| ファームウェア | `PAD_KIND PAD_CHAIR` | **`#define PAD_KIND PAD_FLOOR`** に変えて書き込む |
| Rf | 1kΩ から開始 | 足の圧力は座面より低いので、**2.2〜4.7kΩ から開始**し、06 §6 の手順で決める（かかとの真下で測る） |
| 表面 | 薄い布カバー | **EVA フォームかゴムマット（厚さ 3〜5mm）を上に重ねる**（キャスター・靴から守り、点荷重を分散） |
| 下地 | 滑り止め | カーペットの上なら、下に薄い板（MDF 2.5mm、プラダン）を敷く |

## 3. 部品表（1台分、概算）

| 区分 | 内容 | 概算 |
|---|---|---|
| 回路 | Pico、74HC595 ×2、TBD62083APG ×2、集合抵抗 2.2kΩ ×2、MCP6004 ×4、MCP6002、CD74HC4067 モジュール、Rf/Cf ×16、Vb 生成部品、2×8 ボックスヘッダ ×2 ＋ IDC ＋ フラットケーブル、ユニバーサル基板 | 3,500〜4,500円 |
| マット | Velostat（約 62×50cm。ロール品を推奨）、導電布テープ 約 22m、リップストップ生地、両面テープ | 4,500〜8,000円 |
| 表面・下地 | EVA フォーム／ゴムマット、薄い板 | 1,000〜1,500円 |
| **合計** | | **約 0.9〜1.4万円** |

> 以前「追加 5,000〜7,000円」と見積もったが、マットの面積（Velostat と導電布テープ）が座面の約2倍あるため、上方修正した。電極を 2.75cm 幅のテープ1本で作れば、テープの使用量は減らせる。

## 4. 作り方（06 §4 との違い）

1. 電極の配置：行（左右方向）16本・列（前後方向）16本を、§1 のピッチで描いて導電布テープを貼る。
2. **ケーブルの出口は机側（奥）に集める**：列は奥の縁から出す。行は左右どちらかの縁から出し、縁に沿って奥の角まで這わせる。**椅子側の縁にはケーブルを出さない**（キャスターに踏まれる）。
3. Velostat の継ぎ合わせは、06 §4.3 と同様に**継ぎ目を電極の隙間に合わせる**。
4. 表面に EVA フォームを重ねる。両面テープで端だけ留め、全面は接着しない。
5. 置き方：**座ったときの体の中心線と、マットの中心線（列 7 と 8 の間）を合わせる**。椅子側の縁は、座ったときのかかとより 10cm 程度手前に。

## 5. 立ち上げとテスト

1. `pressure_pad.ino` の `#define PAD_KIND` を `PAD_FLOOR` に（手作り回路なら `#define BOARD` も `BOARD_PICO_DIY` に）して書き込む。
2. 抵抗による1点テスト（06 §6 の 4）：J1 の 4番と J2 の 6番の間に 4.7kΩ → 行3・列5 だけが光ればよい。
3. 表示：
   ```
   cd tools/pressure_pad
   python viewer.py --fake floor     # 実機なし：片足を上げる・つま先立ち・つま先トントンを繰り返す合成データ
   python viewer.py --port COM6      # 実機：マットの種類は自動で判別
   ```
4. **足を乗せない状態で `z`**（ゼロ点）。椅子のキャスターがマットに乗っている場合は、その状態でゼロ点を取る（キャスター分を差し引く）。
5. 画面には左右それぞれの状態（`full` / `toe` / `heel` / `partial` / `lifted`）と位置（cm）が出る。

## 6. 足の検出（v0 のルールベース、`tools/pressure_pad/features.py`）

| 処理 | 内容 |
|---|---|
| 塊の抽出 | しきい値を超えたマスの連結成分 |
| 横に広すぎる塊の分割 | 幅が 13cm を超える塊は、両足がくっついたものとして左右に2分割 |
| かかと＋つま先の統合 | 土踏まずが浮いて、1本の足が前後2つの塊に分かれることが多いので、横 9cm 以内・前後 24cm 以内の塊をまとめる |
| 左右の判定 | 2つあれば位置で左右。1つだけなら**直前の位置に近い方**（履歴がなければマット中心より左か右か） |
| つま先／かかと | 1フレームでは区別できない（接地部分が短いことしか分からない）。**足全体が着いていたときの位置を覚えておき**、接地部分が前寄りなら `toe`、後ろ寄りなら `heel` |

既知の限界：
- **足首を交差させて床に着けた場合**：左右が入れ替わって判定される可能性がある。机下 ToF や時系列モデル（02 §7）で補う。
- 足の位置は「床に着いている部分の圧力中心」。足首の3D位置ではない（足首は足の位置と向きから IK で求める）。
- 靴・スリッパ・裸足で圧力の分布が変わる。しきい値は Rf とゼロ点に合わせて調整する。

## 7. 融合での役割（02 §6.3・§7 と対応）

- 床マットは**机座標系 D に固定**されている（椅子マットは椅子座標系 C）。両足の接地位置は D 系、骨盤は C 系で分かるので、**脚の長さの拘束から椅子の位置・回転（`T_DC`）を推定する手がかり**になる。
- 接地中は足の位置を固定（foot lock）し、アバターの足が滑るのを防ぐ。
- 浮いた足（脚組み・膝上げ）は床マットでは見えないので、机下 ToF の担当になる。
