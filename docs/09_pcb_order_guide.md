# 09. プリント基板を「部品付き」で注文する手順（はんだ付け不要）

> 椅子マット・床マットの読み取り基板を、**部品をすべて実装した状態**で JLCPCB（中国の基板メーカー、日本へ発送可）に注文する手順です。
> 届いたら USB-C をつないでプログラムを書き込むだけで使えます。**はんだごては使いません。**
> 基板の中身の説明は [`hardware/pressure_pad_pcb/README.md`](../hardware/pressure_pad_pcb/README.md) にあります。

---

## 0. 先に知っておいてほしいこと

- この基板の設計データは、プログラム（`gen_board.py`）で自動生成し、自動配線と設計ルールチェック（DRC：エラー0、未配線0）を通したものです。**まだ誰も実物を作って動かしていない「試作第1版」**です。
- そのため、最初は **2枚だけ部品付きで注文**することをおすすめします（椅子用1枚・床用1枚）。基板そのものは最低 5枚からの製造ですが、部品を付けるのは 2枚だけにできます。
- 電子回路に詳しい知り合いがいれば、注文前に `hardware/pressure_pad_pcb/README.md` の回路説明と `jlcpcb/netlist.md`（接続一覧）を見てもらうと安心です。
- 部品の在庫や価格は日々変わります。注文画面で「在庫なし」と出た部品の対処は §5 にあります。

### 費用の目安（2026年10月時点の想定。注文画面の表示が正）

## 1. 注文に使うファイル

このリポジトリの `hardware/pressure_pad_pcb/jlcpcb/` フォルダにある 3つを使います（GitHub から ZIP でダウンロードする方法は 08 §2.1 と同じ）。

| ファイル | 中身 | どこで使う |
|---|---|---|
| `gerbers.zip` | 基板の製造データ（**解凍しないでそのまま**使う） | 最初のアップロード |
| `bom.csv` | 部品表（どの部品を、どこに、何個） | 部品実装の画面 |
| `cpl.csv` | 部品の位置と向き | 部品実装の画面 |

---

## 2. 基板の注文

1. JLCPCB のサイト（jlcpcb.com）でアカウントを作る（メールアドレスで登録）。
2. トップページの「**Add gerber file**」に `gerbers.zip` をドラッグする。数十秒で基板の画像が出る。
3. 設定を確認・変更する（**太字**以外は最初のままでよい）：

| 項目 | 設定 |
|---|---|
| Base Material | FR-4 |
| **Layers** | **4**（自動で 4 になっているはず） |
| Dimensions | 120 × 85 mm（自動） |
| PCB Qty | 5 |
| PCB Thickness | 1.6 |
| PCB Color | 好みで（緑が最安・最短） |
| Surface Finish | HASL (with lead) で可。鉛を避けたいなら LeadFree HASL |
| **Remove Order Number** | 「**Specify a location**」ではなく、迷ったら「Yes（有料のことがある）」か初期値のまま |

4. 下の「**PCB Assembly**」（部品実装）を **ON** にする。
   - **PCBA Type**：**Standard**（箱型コネクタが「挿入部品」なので Standard が必要。Economic を選ぶと挿入部品が付かない）
   - **Assembly Side**：Top Side
   - **PCBA Qty**：**2**
   - Tooling holes：Added by JLCPCB
   - Confirm Parts Placement：**Yes**（部品の向きを工場の技術者に確認してもらう。おすすめ）
5. 「**NEXT**」→ 基板の画像を確認 →「**NEXT**」。

## 3. 部品表と配置ファイルを読み込む

1. 「Add BOM File」に **`bom.csv`**、「Add CPL File」に **`cpl.csv`** をアップロード →「**Process BOM & CPL**」。
2. 部品の一覧が出る。各行の右端に ✓ が付いていれば、その部品は見つかっています。
   - 行の「**Designator**」が R1, R2… のように並び、「**Matched Part**」に部品番号（C21190 など）が出ていれば OK。
3. 「**NEXT**」。

## 4. 部品の向きを確認する（大事）

1. 基板の上に部品が並んだ画像が出る。**IC（黒い四角い部品）の「1番ピンの印」（小さな点・ポッチ）が、基板の印刷の「1」や▲の位置と合っているか**を見る。特に次の部品：

| 記号 | 部品 | 確認ポイント |
|---|---|---|
| U1 | RP2040（真ん中付近の正方形） | 角の点の位置 |
| U10〜U13、U30、U31 | 74HC595 / 74HC4051（細長い 16ピン） | 端の点の位置 |
| U20〜U24 | MCP6004（細長い 14ピン） | 端の点の位置 |
| U2 | フラッシュメモリ（8ピン） | 端の点の位置 |
| U3 | 電源 IC（3本足＋大きな放熱タブ） | 大きなタブが1本足の反対側 |
| Q1〜Q28 | トランジスタ（3本足） | 3本の足が基板のパッドに乗っているか |
| U40 | 動きセンサー（とても小さい） | 角の点の位置 |
| J5 | USB-C | 差し込み口が基板の外側（左）を向いているか |

2. ずれている部品は、画面上で部品をクリックして「Rotate」ボタンで回し、合わせる。分からなければ、§2 の「Confirm Parts Placement：Yes」にしておけば、工場の技術者が確認・修正してくれる（確認のメールが来ることがある）。
3. 「**NEXT**」→ 品名（Product Description）を選ぶ（「**Research\Education\DIY\Entertainment**」→「Development Board」など）→「**SAVE TO CART**」。

## 5. 部品が「在庫なし」「見つからない」と出たとき

| 状況 | 対処 |
|---|---|
| 抵抗・コンデンサが在庫なし | 行の「Search」から、**同じ値・同じサイズ（0603 / 0805）**で「Basic」と書かれた部品を選ぶ |
| 74HC4051D が在庫なし | 「74HC4051」で検索し、パッケージが **SOIC-16** のもの（例：TI の CD74HC4051M）を選ぶ |
| MCP6004 が在庫なし | 「MCP6004」で検索、**SOIC-14** のものを選ぶ。なければ相談してください（ピン配置の同じ代替品を確認します） |
| RP2040 が在庫なし | 待つ（代替品はありません） |
| その他・判断に迷う | その行の部品は付けない（「Do not place」）にせず、**注文を進めないで相談**してください |

## 6. 支払いと発送

1. カートを開き、基板と部品実装が両方入っていることを確認。
2. 発送方法を選ぶ（安い通常便で 1週間前後、急ぐなら DHL など）。
3. 支払い（クレジットカード、PayPal など）。
4. 「Order History」で進み具合が見られる。工場の確認で質問メールが来たら、翻訳ツールで読み、分からなければ相談してください。
5. 日本では、受け取り時に**消費税・通関手数料**の支払いを求められることがあります（数百円〜）。

## 7. 届いたら（はんだ付けなし）

1. 見た目の確認：部品が欠けていないか、USB-C の差し込み口があるか。
2. **プログラムを書き込む**（初回は自動で書き込みモードになっています）：
   1. Arduino IDE（08 §2.2 の手順で準備）で `firmware/pressure_pad/pressure_pad.ino` を開く。
   2. 先頭の設定：`#define BOARD BOARD_PCB_V1`（最初からこの設定）、椅子用は `#define PAD_KIND PAD_CHAIR`、床用は `PAD_FLOOR`。
   3. 「ツール」→「ボード」→「Raspberry Pi Pico/RP2040/RP2350」→「**Generic RP2040**」を選ぶ。
   4. 「ツール」→「Flash Size」→「**16MB (no FS)**」。
   5. USB-C ケーブルで基板とパソコンをつなぐ。**新品の基板は自動で「RPI-RP2」という USB メモリとして見える**（見えない場合は、基板の **BOOT** ボタンを押したまま **RESET** ボタンを押して離す）。
   6. 「ポート」で「UF2 Board」を選び、書き込み（→ボタン）。
   7. 書き込み後、基板の LED がゆっくり点滅すれば動作中（表示ツールとつながっている間）。
3. マットをつなぐ：椅子マットは J1（座面の行）・J2（座面の列）・J3（背もたれの行）・J4（背もたれの列）、床マットは **J1 と J2 だけ**。フラットケーブルの赤い線が、基板に印刷された▲（1番ピン）側。
4. 表示ツール：`py viewer.py --port COM5`（基板の種類・マットの種類・抵抗値は自動で判別されます）。
5. 誰も乗っていない状態で `z` → 座る。

### うまく動かないとき
- 書き込みできない → BOOT を押したまま RESET（§7.2-5）。それでも「RPI-RP2」が出ないなら、USB ケーブル（データ通信用か）を確認。
- 全部 0 のまま → マットのケーブルの向き（赤い線＝▲）を確認。
- Arduino IDE のシリアルモニタで `INFO` と送ると、`"board":"pcb_v1"` と返ってくるはずです。`DUMP` で数値も見られます（08 §3）。
- それでもだめなら、症状と `DUMP` の結果を教えてください。
